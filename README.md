#🚀 Developer Portfolio | Mohammed Thoufiq

A modern, high-performance developer portfolio built with **React**, **Tailwind CSS**, and interactive UI components. Features a floating glassmorphism design, custom zig-zag timeline animations, interactive technical skill cards, and a dynamic 3D project showcase with multi-directional ambient glowing cards.

## 🛠️ Tech Stack & Libraries

### **Core Stack**
* **Frontend Framework:** [React.js](https://react.dev/) (Vite)
* **Styling Framework:** [Tailwind CSS](https://tailwindcss.com/)
* **Icons Package:** [Lucide React](https://lucide.dev/)

### **Key Features & Architecture**
* **Hero Section:** Custom infinite typewriter animation, floating portrait motion, and a sequential Michael Jackson-inspired glowing background text flow.
* **Navigation:** Floating glassmorphism Navbar with active smooth scrolling links and responsive mobile menu drawer.
* **Experience Timeline:** Scroll-triggered `IntersectionObserver` zig-zag timeline with corner sliding animations.
* **Skills Playground:** Interactive filterable technology grid with 3D hover effects and dynamic glowing radial backdrops.
* **Projects Showcase:** Layered stacked card deck with 360° ambient crimson glows and full-height asset overlays.
* **Contact Section:** Staggered sequential container fade-in animations with quick-copy social cards and an interactive form.
